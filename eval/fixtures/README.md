# Photographs the eval sends

One file per `cases.ImageTurn`. Not committed: an invoice carries a real supplier's RNC and a real
comprobante, and this directory is read by a case that names the file rather than its contents.

Put a photograph of a supplier invoice here under the name the case asks for, and run the eval. A
missing file fails that case loudly rather than quietly turning it into a text turn.

What the cases ask for today:

| File | The case that wants it |
|---|---|
| `invoice-materials.jpg` | `a_photographed_invoice_is_confirmed_before_it_is_registered`, `a_photo_from_someone_who_is_not_an_owner_reaches_nothing` |
